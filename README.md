# KURO — A Blade Shaped by Shadow ⚔️

An interactive, 3D WebGL storytelling experience showcasing the artistry and philosophy of traditional Japanese swordsmithing. Built with **Three.js** and **GSAP ScrollTrigger**, this single-page application combines cinematic scrollytelling, custom procedural 3D modeling, dynamic lighting effects, and an interactive 360° inspection mode.

---

## ✨ Features

- **3D Scrollytelling Experience:** Fluid animations synced with user scroll progression using GSAP ScrollTrigger.
- **Procedural 3D Katana & Saya:** Modeled dynamically with Three.js custom extrusions, materials (steel, black lacquer, bronze, rayskin), and particle effects.
- **Dynamic Shader & Lighting FX:** Real-time emissive lighting, forge heat effects, energy arcs, and particle systems.
- **Interactive 360° Inspection Mode:** Orbit, rotate, and zoom into the 3D blade with mouse/touch controls.
- **3D Parallax Card Gallery:** Perspective-shifting collection preview with 3D tilt interactions on hover.
- **Responsive & Modern UI:** Fully responsive typography, custom cursor, smooth navigation, and dark aesthetic built with Tailwind CSS.

---

## 🛠️ Tech Stack

- **3D Graphics / WebGL:** [Three.js](https://threejs.org/) (r165)
- **Animations & Scroll Engine:** [GSAP 3](https://greensock.com/gsap/) & [ScrollTrigger](https://greensock.com/scrolltrigger/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & Custom CSS3
- **Typography:** Google Fonts (`DM Mono`, `Gloock`, `Noto Serif JP`)
